About Project

Smart AI Document Analyzer & Summarizer is an AI-powered web application built using Flask and OpenAI APIs that helps users understand lengthy documents in seconds. Users can upload documents, automatically generate summaries, extract keywords, detect language, and interact with documents using an AI chatbot.

Problem Statement

Reading lengthy reports, PDFs and research documents consumes significant time. Users often struggle to identify important information quickly. Existing tools either provide poor summaries or require manual effort.

Solution

This application uses OpenAI models to intelligently summarize uploaded documents, highlight important keywords, detect language, and answer document-related questions through an AI chatbot.
